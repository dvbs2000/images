图片上传

上传后自动生成可复制的图片链接和 V2EX 格式。

把图片拖到这里

也可以粘贴剪贴板截图（⌘V / Ctrl+V）

连接 GitHub 账号以开始上传

首次需要创建一个仅限此仓库的 Fine-grained token：在 GitHub Settings → Developer settings → Fine-grained tokens 创建，选择 dvbs2000/images，权限设为 Contents: Read and write。粘贴后只保存在当前页面内存中，关闭或刷新页面即清除。

令牌不会上传到本服务以外的地方。

图片会保存在公开仓库 dvbs2000/images 中。请勿上传私密图片。单张图片最大 25 MB。
