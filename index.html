图片上传

使用 GitHub 自带的图片上传。登录 GitHub 后即可上传，无需令牌。

  1. 点击下方按钮，在 GitHub 打开一条新的 Issue 草稿。
  2. 把图片拖进内容框，或点内容框后粘贴剪贴板图片（⌘V / Ctrl+V）。
  3. GitHub 会生成图片链接和 ![](链接) 格式，复制后贴到 V2EX。
  4. 不需要提交 Issue，复制完直接关闭草稿即可。
登录 GitHub 并开始上传

需要在打开的 GitHub 页面登录账号。上传完成后不用点击提交 Issue。

上传的附件由 GitHub 托管。请勿上传私密图片。仓库：dvbs2000/images
