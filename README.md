# Images

A public image repository with a browser uploader.

Open [the upload page](https://dvbs2000.github.io/images/), sign in with GitHub, then drag, choose, or paste an image. It saves the image in this repository and returns a direct URL and Markdown image code.

To display a GitHub-hosted image in a new V2EX topic, select **Markdown** under the topic editor's text format before pasting the image code. V2EX's Default format and replies do not automatically embed GitHub image links; plain Imgur links work there because V2EX recognizes that host.

The uploader's server code is hosted separately so the GitHub client secret stays out of this public repository. The GitHub App installation is limited to this repository.

All uploaded images are public. Do not upload sensitive images.
