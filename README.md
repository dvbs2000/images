# Images

A public image repository with a browser uploader.

Open [the upload page](https://dvbs2000.github.io/images/), sign in with GitHub, then drag, choose, or paste an image. It saves the image in this repository and returns a direct URL and V2EX-ready Markdown.

The uploader's server code is hosted separately so the GitHub client secret stays out of this public repository. The GitHub App installation is limited to this repository.

All uploaded images are public. Do not upload sensitive images.
